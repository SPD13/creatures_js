# reinject_updated_agents.cos — Re-inject Updated Agents (dsbuild 195)

**Source file:** `Assets/Docking Station/Bootstrap/dsbuild 195/reinject_updated_agents.cos`

## Overview

This script **creates no agents** of its own — it is an **autogenerated build/update script** (from the `dsbuild 195` bootstrap folder) that **re-injects** a list of updated agent COS files with `ject … 7` (remove-and-re-run all sections). It is the mechanism by which the dsbuild 195 update refreshes the affected agents in an existing world to their newer versions.

## Re-injected Files

It runs `ject "<file>.cos" 7` for each of:

- DS scroll settings
- Norn Egg layer
- bramboo
- chat - chat module
- chat - chat scripts
- chat - the interpreters
- comms screen
- hoverdoc
- immigrant checker
- message centre
- stinger pod
- training dummy
- warning icons
- workshop screen
- reminder_to_purchase
- zzzy_CheckCreatureDropScript
- zzzz_CreatureHasBeenDropped

Each named file is documented separately; this script merely re-applies them as a batch during the build update.

## Impact on Stimulus / Room CA

None directly. This script creates no agents, emits no stimuli, and writes no Room CA — it only re-injects the listed agent scripts (whose own effects are documented in their respective pages).
